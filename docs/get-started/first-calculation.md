# Din första kalkyl

Här lär du dig att skapa en enkel kalkyl från grunden.

## Steg
1. Logga in i Kalkyldata.
2. Klicka på **Ny kalkyl**.
3. Ge kalkylen ett namn och välj projekt.
4. Lägg till din första del via **+ Del**.
5. Lägg till kalkylartiklar under delen.
6. Spara kalkylen.

## Resultat
Du har en fungerande kalkyl med delar och kalkylartiklar redo att arbeta med.
