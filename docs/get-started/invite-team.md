# Bjud in teamet

Samarbeta i Kalkyldata genom att bjuda in dina kollegor.

## Steg
1. Gå till **Inställningar** > **Team**.
2. Klicka på **Bjud in medlem**.
3. Ange e-postadress och välj roll.
4. Klicka på **Skicka inbjudan**.
5. Teammedlemmen accepterar inbjudan via e-post.

## Resultat
Dina kollegor har tillgång till Kalkyldata med rätt behörighet.
