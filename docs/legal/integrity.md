# Integritet och personuppgifter

Kalkyldata behandlar personuppgifter för att kunna tillhandahålla och utveckla tjänsten.

Vi försöker begränsa behandlingen till den information som behövs för att Kalkyldata ska fungera.

## Vilken information kan behandlas?

Beroende på hur du använder Kalkyldata kan det exempelvis handla om:

- uppgifter om ditt användarkonto,
- namn och e-postadress,
- företagsuppgifter,
- kalkyler och kalkylartiklar,
- kommentarer och projektinformation,
- tekniska uppgifter och loggar,
- information som skickas till support,
- information som behövs för AI-funktionerna.

Du ansvarar för att du har rätt att lägga in och behandla personuppgifter som tillhör andra personer, exempelvis kunder.

## Hur länge sparas informationen?

När ett konto avslutas sparas användarens data i **30 dagar**.

Därefter raderas användarens data permanent och kan inte återställas genom Kalkyldata.

Information som skickats till Kalkyldata via exempelvis support eller e-post kan behöva sparas längre för att hantera ärenden, uppfylla rättsliga skyldigheter eller hantera rättsliga anspråk.

## Externa tjänster

Kalkyldata använder externa tjänster för bland annat:

- drift och hosting,
- databas och lagring,
- AI-funktioner,
- autentisering,
- produktanalys.

Bland annat används Supabase, Render, OpenAI, Anthropic och PostHog.

## AI och personuppgifter

När du använder AI-agenten kan information från din fråga och din kalkyl skickas till den AI-tjänst som används.

Beroende på funktionen kan hela eller delar av kalkylen skickas.

Läs mer om detta på sidan **[AI och databehandling](../ai-och-databehandling/)**.

## Dina rättigheter

Du har rättigheter enligt GDPR, exempelvis rätt att begära information om vilka personuppgifter som behandlas om dig och i vissa fall begära rättelse, radering eller begränsning av behandlingen.
