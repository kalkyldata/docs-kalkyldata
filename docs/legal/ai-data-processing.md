# AI och databehandling

Kalkyldata använder AI för att hjälpa dig att arbeta med kalkyler och använda tjänsten.

AI-agenten kan bland annat hjälpa dig att hitta kalkylartiklar, föreslå material och arbetstider och svara på frågor om Kalkyldata.

## Vilka AI-tjänster används?

Kalkyldata använder externa AI-tjänster, bland annat:

- **OpenAI**
- **Anthropic (Claude)**

Vilka modeller som används kan förändras när Kalkyldata utvecklas.

## Vad skickas till AI?

För att AI-agenten ska kunna svara på din fråga kan information från din fråga och den aktuella kalkylen skickas till den AI-tjänst som används.

Beroende på uppgiften kan det innebära att:

- din fråga skickas,
- relevant information från kalkylen skickas,
- delar av kalkylen skickas,
- hela den aktuella kalkylen skickas.

AI-agenten får inte automatiskt tillgång till all information i Kalkyldata. Vilken information som skickas beror på vad AI-agenten behöver för att utföra uppgiften.

## Används kalkyler för att träna AI?

**Nej.**

Kalkyldata använder inte användarnas kalkyler för att träna en generell AI-modell som sedan används av andra.

Kalkyldata kan däremot använda information från användningen av AI-funktionerna för att utveckla och förbättra Kalkyldata.

Det kan exempelvis handla om att förbättra AI-agentens funktioner, svar och användarupplevelse.

## Kan kunduppgifter skickas till AI?

Ja, om en kalkyl innehåller personuppgifter kan dessa i vissa fall följa med när information från kalkylen skickas till AI-agenten.

Lägg därför inte in känsliga personuppgifter eller annan information som inte behövs för kalkylarbetet.

Du ansvarar för att du har rätt att behandla och använda uppgifterna.

## Kontrollera alltid AI-agentens svar

AI-agenten är ett hjälpmedel och kan göra fel.

Kontrollera alltid AI-genererade:

- materialförslag,
- kalkylartiklar,
- mängder,
- arbetstider,
- priser,
- beräkningar,
- tekniska svar.

AI-agenten ersätter inte din egen yrkeskunskap och bedömning.
