# Installation och inställningar

Konfigurera Kalkyldata för att passa din organisations behov.

## Grundinställningar
1. Logga in som administratör.
2. Gå till **Administration** > **Inställningar**.
3. Ange organisationsnamn, logotyp och standardvaluta.

## Integrationer
- Anslut till externa system under **Integrationer**.
- Se [n8n-integration](/docs-kalkyldata/referens/n8n-integration/) för automatiseringsflöden.

## Säkerhet
- Ställ in tvåfaktorsautentisering (2FA) under **Säkerhet**.
- Granska inloggningsloggar under **Aktivitetslogg**.
