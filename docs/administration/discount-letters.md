# Rabattbrev

Rabattbrev låter dig hantera avtalade rabattnivåer per leverantör och kund.

## Skapa ett rabattbrev
1. Gå till **Administration** > **Rabattbrev**.
2. Klicka på **+ Nytt rabattbrev**.
3. Välj leverantör och ange rabattnivåer per artikelgrupp.
4. Ange giltighetstid.
5. Spara.

## Tillämpa ett rabattbrev
1. Öppna en kalkyl.
2. Gå till **Inställningar** > **Rabattbrev**.
3. Välj rätt rabattbrev från listan.
4. Priserna uppdateras automatiskt.
