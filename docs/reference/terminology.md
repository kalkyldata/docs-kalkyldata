# Terminologi

Ordlista över begrepp som används i Kalkyldata.

| Begrepp | Förklaring |
|---|---|
| **Del** | En logisk gruppering av arbetsmoment i en kalkyl. |
| **Uppgift** | En specifik arbetsuppgift inom en del. |
| **Kalkylartikel** | Material eller tjänst med pris och mängd. |
| **Offert** | Rapport som presenterar kalkylens priser för kunden. |
| **Prisprofil** | Konfiguration av pålägg och rabattnivåer. |
| **Rabattbrev** | Avtalad rabattnivå per leverantör och artikelgrupp. |
| **Fork** | Kopia av en kalkylartikel som kan redigeras fritt. |
| **Snapshot** | Sparad version av en artikels pris vid en given tidpunkt. |
