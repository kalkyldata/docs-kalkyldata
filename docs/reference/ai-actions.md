## Vad AI-agenten kan göra

AI-agenten hjälper dig att arbeta snabbare i Kalkyldata. Den kan föreslå kalkylartiklar utifrån det du beskriver, öppna rätt vyer och hjälpa dig att strukturera kalkylen.

När en åtgärd påverkar kalkylen behöver du bekräfta den innan ändringen genomförs.

## Föreslå kalkylartiklar

AI-agenten kan föreslå kalkylartiklar utifrån arbetet du beskriver i chatten.

Förslagen kan innehålla:

* kalkylartikel med uppgifter
* material
* arbetstid
* pris

AI-agenten tar även hänsyn till projektinformationen och dina favoriter när den väljer och rangordnar förslag.

Granska förslaget och välj vilken **del** det ska läggas i. Bekräfta sedan för att lägga till kalkylartikeln i kalkylen.

## Öppna vyer och paneler

AI-agenten kan öppna rätt vy direkt från chatten. När en åtgärd kan utföras visas en knapp i svaret.

| Åtgärd                     | Vad som händer                                                        |
| -------------------------- | --------------------------------------------------------------------- |
| **Visa kalkyl**            | Öppnar kalkylpanelen.                                                 |
| **Öppna projektinfo**      | Öppnar projektinformationen för bland annat projekttyp, kund och ort. |
| **Öppna rapporter**        | Öppnar rapportvyn med den aktuella kalkylen.                          |
| **Mina kalkylartiklar**    | Öppnar listan med dina egna kalkylartiklar.                           |
| **Skapa kalkylartikel**    | Öppnar verktyget för att skapa en ny kalkylartikel.                   |
| **Visa kalkylartikel**     | Öppnar en specifik kalkylartikel.                                     |
| **Redigera kalkylartikel** | Öppnar en egen kalkylartikel för redigering.                          |
| **Importera kalkyldata**   | Öppnar importfunktionen för JSON.                                     |
| **Exportera kalkyldata**   | Öppnar exportfunktionen för hela kalkylen.                            |
| **Visa favoriter**         | Visar dina stjärnmärkta kalkylartiklar.                               |

## Strukturera kalkylen

AI-agenten kan hjälpa dig att skapa en **del** i kalkylen.

Beskriv vilken del du vill skapa, till exempel `Belysning plan 2`. Agenten kan då lägga upp delen med det namn du anger. Du bekräftar innan ändringen görs.

## Starta en rundtur

AI-agenten kan starta en guidad rundtur direkt från chatten.

Du kan välja mellan:

* hela introduktionen
* kalkylen
* rapporterna
* kalkylartiklarna
* favoriterna

Använd rundturen när du vill lära dig hur en viss del av Kalkyldata fungerar.

## Det AI-agenten inte gör

AI-agenten ändrar inte befintliga uppgifter eller skickar något till kunden på egen hand.

Den:

* ändrar inte priser, arbetstider eller antal i befintliga rader
* tar inte bort delar, uppgifter eller rapporter
* publicerar inte kalkylartiklar åt dig
* skickar inget till kunden

Du behåller kontrollen över ändringar som påverkar kalkylen.

## Rapportera ett felaktigt svar

Om AI-agentens svar inte stämmer, eller om svaret är dåligt, kan du klicka på **tummen ner** under svaret.

Då följer frågan och svaret med i rapporten till Kalkyldata. Det hjälper oss att upptäcka fel och förbättra AI-agenten.
