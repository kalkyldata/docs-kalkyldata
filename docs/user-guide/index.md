# Användarguide

Välkommen till användarguiden för Kalkyldata.

Här hittar du guider som hjälper dig att använda programmets olika funktioner – från att skapa din första kalkyl till att arbeta med rapporter, materialpriser och egna kalkylartiklar.

Guiderna är uppdelade efter programmets olika arbetsområden.

## Chat och AI-agenten

Lär dig använda AI-agenten, skriva effektiva frågor, söka efter kalkylartiklar och förstå hur chatten fungerar.

## Kalkyl

Lär dig bygga och redigera kalkyler, arbeta med delar och kalkylartiklar samt förstå hur materialpriser beräknas.

## Rapporter

Skapa offerter, materiallistor och andra rapporter med rätt prisstrategi och inställningar.

## Kalkylartiklar

Skapa, redigera, publicera och återanvänd egna kalkylartiklar för dig själv eller hela företaget.

## Hittar du inte det du söker?

Om du inte hittar svaret i användarguiden kan du fråga AI-agenten direkt i chatten. AI-agenten kan ofta hjälpa dig att hitta rätt funktion eller förklara hur den fungerar.
