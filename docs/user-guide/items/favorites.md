# Favoriter och snapshots

Spara dina mest använda artiklar som favoriter och ta snapshots för historik.

## Favoriter
1. Öppna en kalkylartikel.
2. Klicka på stjärnikonen (☆) för att lägga till den som favorit.
3. Favoriter visas under **Mina favoriter** i biblioteket.

## Snapshots
En snapshot sparar artikelns nuvarande pris och specifikation.
1. Öppna en artikel.
2. Klicka på **Ta snapshot**.
3. Ange ett namn, t.ex. "Pris 2025-Q1".
4. Snapshotet sparas under artikelns historik.

## Tips
- Snapshots är användbara för att jämföra priser över tid.
