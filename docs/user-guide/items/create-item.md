# Skapa egna kalkylartiklar

Bygg upp ett eget artikelbibliotek anpassat för ditt företag.

## Steg
1. Gå till **Kalkylartiklar** i menyn.
2. Klicka på **+ Ny artikel**.
3. Fyll i namn, artikelnummer, enhet och pris.
4. Lägg till en beskrivning om det behövs.
5. Klicka på **Spara**.

## Resultat
Artikeln finns nu i ditt bibliotek och kan läggas till i valfri kalkyl.
