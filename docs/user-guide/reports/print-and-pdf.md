# Utskrift och PDF

Använd inställningarna under **Visning** för att bestämma vad rapporten ska visa och hur den ska se ut vid utskrift. Du kan styra gruppering, detaljer, kolumner, sidbrytningar och pappersformat utan att ändra själva kalkylen.

## Så förbereder du utskriften

1. Öppna rapporten.
2. Klicka på **Inställningar**.
3. Välj fliken **Visning**.
4. Välj hur rapporten ska grupperas, till exempel per **Del** eller **Kalkylartikel**.
5. Välj vilka detaljer och kolumner som ska visas.
6. Välj pappersformat och orientering.
7. Stäng inställningspanelen och klicka på **Skriv ut**.
8. Välj skrivare eller **Spara som PDF** i utskriftsdialogen.

## Inställningar under Visning

| Inställning                   | Vad den gör                                                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Gruppering**                | Anger rapportens primära och eventuella sekundära gruppering, till exempel **Del**, **Kalkylartikel**, **Etapp** eller **Resurstyp**. |
| **Visa uppgifter**            | Visar eller döljer uppgifterna under varje kalkylartikel.                                                                             |
| **Visa interna anteckningar** | Visar anteckningar som är avsedda för internt bruk.                                                                                   |
| **Dölj nollrader**            | Döljer rader som saknar pris eller arbetstid.                                                                                         |
| **Visa prisnotis**            | Visar en ruta överst i rapporten som förklarar vilken prisstrategi som har använts.                                                   |
| **Kolumner**                  | Visar eller döljer de kolumner som rapportmallen erbjuder, till exempel **Antal**.                                                    |
| **Sidbrytning per del**       | Börjar varje del på en ny sida vid utskrift.                                                                                          |
| **Pappersformat**             | Väljer `A4` eller `A3`.                                                                                                               |
| **Orientering**               | Väljer stående eller liggande format.                                                                                                 |

En räknare visar hur många rader rapporten innehåller med de valda inställningarna. Du ser därför direkt hur ändringarna påverkar rapportens omfattning.

## Spara visningen som standard

Om du ofta använder samma visning kan du spara den som standard för rapportprofilen.

Klicka på **Spara som profilens standard** när rapporten är inställd som du vill ha den. Nästa rapport som använder samma profil startar då med dessa inställningar.

## Bra att veta

* **Sidbrytning per del** fungerar för rapportmallarna **Kundoffert** och **Kundoffert (material/arbete uppdelat)**.
* Använd liggande `A3` när rapporten innehåller många kolumner, till exempel en detaljerad materiallista.
* Förhandsvisningen visar rapportens layout och sidbrytningar så att du kan kontrollera resultatet innan du skriver ut.
* Stäng av **Visa interna anteckningar** när rapporten ska skickas till kunden.
* Inställningarna för visning påverkar rapporten, inte innehållet i kalkylen.
