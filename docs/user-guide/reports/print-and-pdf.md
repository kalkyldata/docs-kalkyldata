# Utskrift och PDF

Exportera dina rapporter som PDF eller skriv ut dem direkt.

## Generera PDF
1. Öppna rapporten du vill exportera.
2. Klicka på **Exportera PDF**.
3. Välj sidformat och orienteringsinställningar.
4. Klicka på **Ladda ned PDF**.

## Skriva ut
1. Öppna rapporten.
2. Klicka på **Skriv ut** eller använd webbläsarens utskriftsfunktion (Ctrl+P).
3. Välj skrivare och inställningar.

## Tips
- PDF-formatet bevarar layout och teckensnitt exakt som i förhandsgranskningen.
