# Validering och felsökning av rapporter

Kontrollera att din rapport är korrekt innan du skickar den.

## Automatisk validering
Kalkyldata validerar automatiskt:
- Saknade priser eller mängder.
- Ogiltiga prisstrategier.
- Tomma obligatoriska fält.

Valideringsvarningar visas i ett gult fält längst upp i rapporten.

## Åtgärda fel
1. Klicka på varningen för att se detaljer.
2. Gå till den del i kalkylen som behöver åtgärdas.
3. Rätta felet och återgå till rapporten.
4. Valideringsvarningen försvinner automatiskt när felet är löst.

## Tips
- Kör alltid validering innan du genererar slutlig PDF.
