# Import och export av kalkyldata

Du kan importera data till och exportera data från Kalkyldata i flera format.

## Exportera
1. Öppna kalkylen.
2. Klicka på **Exportera** i verktygsfältet.
3. Välj format (Excel, CSV eller PDF).
4. Klicka på **Ladda ned**.

## Importera
1. Klicka på **Importera** i verktygsfältet.
2. Välj fil (Excel eller CSV).
3. Mappa kolumnerna mot fälten i Kalkyldata.
4. Klicka på **Importera**.

## Tips
- Kontrollera alltid importen i en testmiljö innan du kör skarpt.
