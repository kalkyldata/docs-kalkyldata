# Kommentarer och arbetsflöde

Samarbeta effektivt med kommentarer och arbetsflödesstatus direkt i kalkylen.

## Lägga till kommentarer
1. Klicka på en artikel eller del.
2. Välj **Kommentar** i sidopanelen.
3. Skriv din kommentar och klicka på **Skicka**.

## Arbetsflödesstatus
- Markera delar som **Granskas**, **Godkänd** eller **Klar** för att hålla koll på progress.
- Statusändringar syns för alla teammedlemmar i realtid.

## Tips
- Tagga kollegor med @ i kommentarer för att meddela dem.
