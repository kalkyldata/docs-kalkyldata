# Skapa och hantera delar

Delar strukturerar din kalkyl i logiska arbetsmoment.

## Skapa en ny del
1. Öppna kalkylen.
2. Klicka på **+ Del**.
3. Ange ett namn för delen, t.ex. "Stomme".
4. Klicka på **Spara**.

## Hantera delar
- **Byt namn**: klicka på delens namn och redigera.
- **Flytta**: dra och släpp för att ändra ordning.
- **Ta bort**: klicka på menyn (⋮) bredvid delen och välj **Ta bort**.
