Använd sökning när du letar efter en viss kalkylartikel eller ett materialnummer i kalkyltabellen. Använd filter när du vill visa ett urval av kalkylen. Du kan också sortera tabellen och välja vilka kolumner som ska visas.

## Sök i kalkylen

1. Öppna kalkylpanelen.
2. Klicka i fältet **Sök artikel, art.nr…**.
3. Skriv hela eller delar av ett namn, en kategori eller ett artikelnummer.
4. Matchande rader visas direkt i kalkyltabellen.
5. Klicka på **X** i sökfältet för att visa hela kalkylen igen.

Sökningen påverkar bara vilka rader som visas. Kalkylens innehåll och totalsummor ändras inte.

## Filtrera kalkylen

1. Klicka på filterikonen till höger om sökfältet.
2. Välj en eller flera **Delar**.
3. Välj en eller flera **Kategorier**.
4. Välj ett minsta värde för **Arbetstid** om du vill visa större arbetsinsatser.
5. Välj ett minsta värde för **Materialkostnad** om du vill visa dyrare kalkylartiklar.
6. Klicka **Rensa alla** för att ta bort alla aktiva filter.

Aktiva filter visas som etiketter under sökfältet. Klicka på **X** i en etikett för att ta bort ett enskilt filter.

## Sortera tabellen

Klicka på en kolumnrubrik med sorteringssymbol för att sortera kalkylartiklar eller uppgifter. Klicka igen för att växla mellan stigande och fallande ordning.

Du kan bland annat sortera på:

- benämning,
- kategori,
- antal,
- total tid,
- totalt material,
- moment,
- grossist,
- yrkesroll.

Sortering påverkar bara ordningen i tabellen. Kalkylens innehåll ändras inte.

## Visa eller dölj kolumner

1. Klicka **Kolumner** i kalkylpanelens verktygsrad.
2. Välj fliken **Delar**, **Artiklar** eller **Uppgifter**.
3. Klicka på en kolumn för att visa eller dölja den.
4. Stäng menyn genom att klicka utanför den.

Att dölja en kolumn påverkar bara visningen. Informationen finns fortfarande kvar i kalkylen.

På mobil visas de viktigaste kolumnerna från början för att ge bättre överblick.

Se [Kolumnreferens](/referens/kolumner/) för en beskrivning av alla kolumner.

## Bra att veta

- Du kan kombinera sökning och filter.
- Klicka **Rensa alla** för att visa hela kalkylen igen.
- Ett filter på del visar bara den eller de valda delarna.
- Ett filter på kategori eller kostnad kan dölja delar som inte längre innehåller några träffar.
- Sökning, filter, sortering och dolda kolumner påverkar bara hur kalkylen visas. Kalkylens innehåll ändras inte.
- Du kan också fråga AI-agenten om kalkylen, till exempel `Vilka kalkylartiklar innehåller Schneider-material?` eller `Vilka delar har högst materialkostnad?`
