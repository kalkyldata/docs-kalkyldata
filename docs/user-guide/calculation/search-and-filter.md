# Sök och filtrera i kalkylen

Hitta snabbt rätt del eller artikel med hjälp av sök- och filterfunktionerna.

## Söka
1. Klicka på sökfältet längst upp i kalkylvyn.
2. Skriv ett sökord (artikel, del eller beskrivning).
3. Resultaten visas filtrerade i realtid.

## Filtrera
- Filtrera på **del** för att visa endast en del i taget.
- Filtrera på **artikeltyp** (material, tjänst) med filtermenyn.
- Kombinera filter för att snäva in resultaten ytterligare.
