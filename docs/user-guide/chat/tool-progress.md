# Verktygsindikering

När AI-agenten arbetar visas en statusrad under ditt meddelande. Den visar att AI-agenten fortfarande bearbetar din fråga och kan även beskriva vad den gör just nu.

För att besvara dina frågor använder AI-agenten olika verktyg. Beroende på vad du ber om kan den till exempel söka efter kalkylartiklar, läsa information i din kalkyl, hämta materialpriser eller öppna olika delar av programmet.

## Så fungerar statusraden

1. Skicka en fråga till AI-agenten.
2. En statusrad visas medan frågan behandlas.
3. Statusraden kan ändras flera gånger beroende på vilka verktyg AI-agenten använder.
4. När svaret är klart ersätts statusraden av AI-agentens svar.

## Exempel på statusmeddelanden

| Status | Vad det betyder |
| --- | --- |
| **Tänker** | AI-agenten analyserar din fråga och planerar nästa steg. |
| **Söker kalkylartiklar** | AI-agenten letar efter relevanta kalkylartiklar. |
| **Hämtar priser** | AI-agenten hämtar materialpriser och använder dina rabattbrev när det är aktuellt. |
| **Läser kalkylen** | AI-agenten granskar innehållet i den aktuella kalkylen. |
| **Öppnar vy** | AI-agenten förbereder en vy eller funktion som du har bett om. |

Vilka statusmeddelanden som visas beror på vilken uppgift AI-agenten utför.

## Bra att veta

- Det är normalt att statusraden ändras flera gånger innan svaret visas.
- Så länge statusraden visas arbetar AI-agenten fortfarande.
- Skicka inte samma fråga igen medan statusraden visas. Då startas en ny körning.
- Om något går fel visas normalt ett felmeddelande. Du kan då prova att skicka frågan igen.

## Behöver jag göra något?

Nej. Statusraden är bara information om vad AI-agenten arbetar med. Vänta tills svaret visas innan du fortsätter.
