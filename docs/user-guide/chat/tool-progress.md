# Verktygsindikering

När AI-agenten utför en åtgärd visas en indikering i chatten som berättar vad agenten gör.

## Vad indikeringen visar
- **Söker…** – agenten söker i artikeldatabasen.
- **Lägger till…** – agenten lägger till en artikel i kalkylen.
- **Beräknar…** – agenten beräknar priser eller mängder.

## Varför det är användbart
Du kan följa agentens arbete i realtid och avbryta om något inte stämmer. Om indikeringen fastnar längre än förväntat kan du skriva "avbryt" i chatten.
