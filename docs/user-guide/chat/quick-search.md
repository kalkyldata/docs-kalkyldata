# Snabbsök i chatten

Med snabbsök kan du söka direkt i chatten utan att lämna konversationen.

## Så här gör du
1. Skriv `/sök` följt av sökterm i chattrutan, t.ex. `/sök kabel 2,5`.
2. AI-agenten visar matchande artiklar direkt i chatten.
3. Klicka på en artikel för att se detaljer eller lägga till den i kalkylen.

## Tips
- Kombinera söktermer för mer precisa resultat.
- Snabbsök fungerar mot hela artikeldatabasen i realtid.
