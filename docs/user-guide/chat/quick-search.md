Snabbsök hjälper dig att snabbt hitta kalkylartiklar direkt i chattrutan. Funktionen passar bäst när du redan vet vilken kalkylartikel du vill lägga till och inte behöver be AI-agenten skapa ett förslag.

## Så använder du det

1. Klicka i skrivrutan längst ned i chatten.
2. Skriv minst tre tecken av kalkylartikelns namn, till exempel `uttag`.
3. Välj kalkylartikeln i listan som visas.
4. Ange antal.
5. Klicka **Lägg till** för att lägga till kalkylartikeln i kalkylen.

Du kan även välja vilken **del** kalkylartikeln ska läggas i eller öppna **Visa kort** för att granska innehållet innan du lägger till den.

## Vad kan du söka efter?

Snabbsök söker bland publicerade kalkylartiklar och hittar träffar utifrån bland annat:

| Du kan söka på | Exempel |
| --- | --- |
| Kalkylartikelns namn | `vägguttag` |
| Nyckelord | `spotlight` |
| Kategori | `belysning` |
| Beskrivning | `rörelsevakt` |
| E-nummer | `2203006` |

Ju mer specifik sökningen är, desto färre och mer relevanta träffar får du.

## Söktips

| Exempel | Resultat |
| --- | --- |
| `infälld spot` | Söker efter kalkylartiklar som innehåller båda orden. |
| `"infälld downlight"` | Söker efter den exakta frasen. |
| `uttag -utomhus` | Utesluter kalkylartiklar som innehåller `utomhus`. |
| `nr:2203006` | Söker efter ett E-nummer. |
| `kat:belysning` | Begränsar sökningen till en kategori. |

Använd raka citationstecken (`"`).

## Bra att veta

- Du måste skriva minst tre tecken innan söklistan visas.
- **Retur** skickar alltid meddelandet till AI-agenten och väljer aldrig en träff i söklistan.
- Snabbsök visar publicerade kalkylartiklar, inklusive dina egna publicerade kalkylartiklar.
- Om kalkylen saknar en del skapas en automatiskt när du lägger till den första kalkylartikeln.

## När använder jag AI-agenten istället?

Använd **snabbsök** när du redan vet vilken kalkylartikel du vill lägga till.

Använd **AI-agenten** när du vill beskriva ett arbete, få förslag på flera kalkylartiklar eller låta AI-agenten bygga en större del av kalkylen åt dig.
