# Mappträdet

Mappträdet låter dig bläddra bland publicerade kalkylartiklar som är sorterade i kategorier och mappar. Använd det när du vill hitta en kalkylartikel genom att bläddra i stället för att söka.

## Öppna mappträdet

Du kan öppna mappträdet på flera sätt:

* Klicka på mappikonen vid skrivrutan.
* Välj **Öppna i mappträdet** överst i snabbsökets träfflista.
* Be AI-agenten att visa kategorier.

Alla tre alternativen öppnar samma mappträd.

## Favoriter och Mina artiklar

Överst i trädet finns två egna mappar:

| Mapp              | Innehåll                                              |
| ----------------- | ----------------------------------------------------- |
| **Favoriter**     | Kalkylartiklar som du har stjärnmarkerat              |
| **Mina artiklar** | Kalkylartiklar som du själv har skapat och publicerat |

## Sök i mappträdet

Skriv i sökfältet överst för att hitta mappar och kalkylartiklar. Klicka på en träff för att öppna mappen eller kalkylartikeln.

## Information om kalkylartikeln

Varje kalkylartikel visar:

* antal uppgifter
* arbetstid i timmar
* materialkostnad baserad på **ditt bästa nettopris**

Det bästa nettopriset är det lägsta priset efter dina rabattbrev. Om ett nettopris saknas används kalkylartikelns sparade pris.

Finns en **i**-ikon bredvid kalkylartikeln finns en beskrivning. Håll muspekaren över ikonen på dator eller tryck på den på mobilen.

## Lägg till i kalkylen

Klicka på en kalkylartikel för att ange antal och lägga till den i kalkylen. Kalkylartikeln läggs som standard till i den aktuella delen.

Klicka på **nedåtpilen (v)** för att visa fler alternativ:

* **Visa kort** – öppnar mer information om kalkylartikeln.
* **Byt del** – välj en annan del att lägga till kalkylartikeln i.
